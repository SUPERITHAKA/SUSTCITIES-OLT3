# Sustainable Cities - Online Learning Tool (OLT)

LUT University | Sustainable Cities | 2026

## Project objective

Develop, improve, and test an accessible and engaging
online learning experience for stormwater management
and urban flood resilience.

## Project components

- Web application: React + Vite
- Learning modules and interactive quizzes
- Accessibility and responsive design
- User testing and evaluation
- LUT-format academic report
- Team collaboration through GitHub

## Project structure

- web/        React application
- report/     LUT LaTeX report and chapters
- docs/       Research, meetings, testing
- .github/    GitHub Actions
- .vscode/    Shared editor configuration

## Running the web application

From the project root:

    npm install --prefix web
    npm run dev --prefix web

Open the local address displayed in the terminal.

## Production build

    npm run build --prefix web

## Team workflow

Create a branch for each feature, open a pull request,
and merge reviewed changes into main.
