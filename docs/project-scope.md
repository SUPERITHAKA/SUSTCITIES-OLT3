# Project Scope

## Main objective

Further develop and test an accessible and engaging
online learning tool for stormwater and flood resilience.

## Initial learning topics

1. Stormwater and the urban water cycle
2. Flood risk in cities
3. Nature-based stormwater management
4. Flood resilience and preparedness

## Core functionality

- Learning modules
- Interactive knowledge checks
- Learning progress indicator
- Accessible controls and text
- Responsive mobile-first interface

## Evaluation

- Usability testing
- Accessibility testing
- Learning effectiveness
- Participant feedback
- Improvements based on testing
