# Sustainable Cities OLT - Academic Report

## Official LUT template

https://elut.lut.fi/en/completing-studies/theses/masters-thesis

The official LUT LaTeX template is linked from that page.

Download the complete official template from Overleaf and
extract its files into:

    report/lut-template/

Preserve the original template's formatting files,
document properties, bibliography configuration,
and main LaTeX document.

## Prepared report chapters

The chapters/ directory contains content placeholders
for the course project.

Integrate these with the official LUT main document
by replacing its example chapter inputs.

Example chapter input from the template directory:

    \input{../chapters/01-introduction.tex}

The official template is designed for BSc/MSc theses.
For this course, use its layout as requested and adapt
the academic content to the project report requirements.

Do not describe the course project as a Master's thesis.
