\chapter{PROPOSED USER TESTING PROTOCOL}
\section{Purpose}
Evaluate whether first-time users can navigate the application, complete the learning modules, and understand the feedback given after knowledge checks.

\section{Suggested tasks}
\begin{enumerate}
 \item Open the OLT and identify the three learning topics.
 \item Open the stormwater module and answer its knowledge-check question.
 \item Navigate to a different module and return to the first.
 \item Locate the progress indicator and explain what it represents.
 \item Complete the same tasks using a keyboard only.
\end{enumerate}

\section{Recording observations}
For each participant, record a non-identifying participant code, tested browser/device, task completion, errors, comments, and follow-up questions. Do not publish personal information.
