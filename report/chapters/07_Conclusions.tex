\chapter{CONCLUSIONS}
The Online Learning Tool project has established an initial web-based prototype for communicating stormwater and urban flood resilience concepts. The application provides topic-based content, interactive questions, answer feedback, and a learning progress display.

The project's original aim also includes evaluation of engagement, accessibility, and effectiveness. Those objectives remain incomplete until user testing is performed and the findings have been analyzed. This report is a working project document and will be updated with verified results before submission.
