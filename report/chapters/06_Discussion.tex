\chapter{DISCUSSION}
\section{Interpretation}
The prototype demonstrates a basic interactive format for teaching stormwater and flood resilience concepts. Its impact on learning, however, has not yet been established through user testing. Discussion of educational outcomes will be completed when test results are available.

\section{Limitations}
The present prototype has a small set of learning topics and short multiple-choice checks. Answers are not retained after reloading the page. The accessibility features have not yet undergone formal evaluation. These constraints should inform the next development iteration.

\section{Potential improvements}
Future work may include scenario-based exercises, clearer visual explanations, expanded learning content, accessibility remediation based on testing, and learner progress persistence. Priorities should be linked to the evidence collected by the project team.
