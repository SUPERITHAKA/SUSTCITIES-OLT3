\textbf{Sustainable Cities: Online Learning Tool (OLT) -- Stormwater Management and Flood Resilience}

\vspace{1em}
Course project report\\
Authors: Sustainable Cities OLT Project Team

\vspace{1em}
\textbf{Keywords:} stormwater management; flood resilience; sustainable cities; online learning; accessibility; user-centered design.

\vspace{1em}
The Online Learning Tool (OLT) project aims to further develop and evaluate an accessible, engaging web-based learning experience about urban stormwater management and flood resilience. The initial prototype uses React and Vite, and includes short learning modules, multiple-choice knowledge checks, immediate answer feedback, and an indicator of learning progress. The planned evaluation will investigate usability, accessibility, and learning effectiveness. This report documents the project background, development approach, implementation, and evaluation plan. Empirical evaluation results and conclusions will be added after the planned tests have been completed.
